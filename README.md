# La Casita de Ginger

Sitio web de La Casita de Ginger, una pastelería temática de Chillán que hace tortas, galletas decoradas y preparaciones tradicionales chilenas. Es el proyecto final del ramo Diseño Web de IPlaceX, hecho por el Grupo 5.

## Enlaces

- Sitio publicado en Netlify: https://casita-de-ginger-chillan.netlify.app
- Repositorio: https://github.com/Patgsj/la-casita-de-ginger

## Qué tiene el sitio

- Portada con bienvenida y presentación de Ginger.
- Productos, tortas con sus tarjetas, y la sección de pedidos a medida.
- Fondos de pantalla para descargar.
- Quiénes somos, ubicación, testimonios y formulario de contacto.
- Se adapta a computador, tablet y celular.

## Tecnologías

- HTML y CSS.
- JavaScript para los eventos del sitio.
- Template Assan 3.8, de design_mylife, adaptado al emprendimiento (se mantienen sus créditos).
- GitHub para el código y Netlify para publicarlo.

## Eventos con JavaScript

El archivo `js/formulario.js` valida el formulario de contacto:

- Evento `blur`: cuando se sale de un campo, se revisa y se muestra un mensaje si hay un error.
- Evento `submit`: al enviar, se revisan todos los campos. Si alguno está mal, no se envía y se avisa.

## Estructura

```
index.html      página principal
css/            estilos del template y propios
js/             scripts del template y formulario.js
img/            imágenes del sitio
fonts/          tipografías
```

Abrir `index.html` en el navegador.
